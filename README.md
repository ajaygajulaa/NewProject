# React + Vite starter

A small React and TypeScript app built with Vite.

## Getting started

Use Node.js 22.22.2+ (22.x), 24.15+ (24.x), or 26+ and npm. These versions satisfy the app and test tooling.

```sh
npm ci
npm run dev
```

Open the URL printed by Vite. Edit `src/App.tsx` to change the page; Vite updates it during development.

## Checks and production build

```sh
npm test             # component tests
npm run typecheck    # TypeScript checks
npm run lint         # ESLint
npm run build        # typecheck and build to dist/
npm run preview      # serve the production build locally
```

Preview is for checking the build locally, not a production server.
